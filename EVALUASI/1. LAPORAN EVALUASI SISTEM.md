## 3. EVALUASI FITUR & FUNGSIONALITAS BISNIS

### A. Mode Pembeli (Storefront & Sticky Cart)
* **Katalog Menu:** Menu tersaji dalam bentuk kartu polaroid lengkap dengan foto produk, badge harga, dan status ketersediaan (*Tersedia / Habis*).
* **Keranjang Melayang (Sticky Cart):** Otomatis muncul saat ada menu dipilih, menampilkan subtotal riil, dan memiliki tombol langsung ke WhatsApp.
* **Integrasi WhatsApp:** Menghasilkan pesan terstruktur rapi ke nomor resmi Dulang (+62 877 0339 7035) tanpa perlu pembeli menyusun format teks manual.

### B. Mode Smart QR Stiker (Zero-Typing Reorder)
* **Kasus Stiker Baru (Kosong):** Ketika kardus risoles pertama kali di-scan pembeli, sistem mengenali status *Unused* dan menampilkan form kenalan singkat dengan opsi persetujuan UU PDP.
* **Kasus Repeat Order (Terisi):** Begitu di-scan kembali di hari lain, pembeli langsung disapa namanya, menampilkan tier loyalitas (*Baru / Setia / Sultan Dulang*), dan pesanan dapat langsung dikirim via WA tanpa ketik nama/alamat lagi.

### C. Mode Dapur & Pemilik (Owner Dashboard)
* **Akses Keamanan:** Dilindungi kode PIN pemilik (default: `dulang2020`, dapat diubah sewaktu-waktu di pengaturan).
* **Kelola Menu Interaktif:** Pemilik dapat menambah menu baru, mengedit menu lama, mengubah harga, dan mengunggah foto menu langsung dari HP/laptop.
* **Pengaturan Toko Fleksibel:** Pemilik dapat mengganti foto utama banner, jam operasional ringkas, dan 4 kartu rutinitas harian secara visual.
* **Radar Klaster Sidoarjo:** Menyajikan grafik sebaran alamat pembeli berdasarkan wilayah (Waru, Gedangan, Buduran, Sidoarjo Kota, dll) untuk strategi promo ongkir.

### D. Generator & Cetak Stiker Dus (Sticker Generator)
* **Ukuran Pas:** Layout 20 stiker per lembar kertas A4 Vinyl Doff dengan margin presisi siap potong.
* **Ekspor Dokumen:** Mendukung ekspor langsung ke file **PDF Siap Cetak** dan file **CSV Data QR**.
* **Link Dinamis:** Link yang disematkan ke dalam QR code otomatis mengikuti domain tempat web dibuka (misal `https://dulangin.netlify.app/?scan=DULANG-XXXX`).

## 5. KEPATUHAN HUKUM & PRIVASI DATA (UU PDP NO. 27/2022)
1. **Asas Transparansi:** Form stiker secara jelas menginformasikan bahwa data nama, nomor WhatsApp, dan alamat disimpan khusus untuk mempermudah pengiriman pesanan berikutnya.
2. **Persetujuan Eksplisit (*Explicit Consent*):** Pengguna diwajibkan mencentang klausul persetujuan sebelum data tersimpan, dengan pencatatan stempel waktu digital (*timestamp* ISO 8601).
3. **Retensi & Isolasi Data:** Data disimpan secara terisolasi di sisi klien (*localStorage*) dan siap disinkronkan ke Supabase Cloud dengan enkripsi level basis data dan kebijakan *Row Level Security* (RLS).
